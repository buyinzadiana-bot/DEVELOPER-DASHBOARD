Developer Dashboard

A clean, responsive Developer Dashboard built with React, TypeScript, Vite, and Tailwind CSS.  
This project brings together data from real APIs — showing your **GitHub profile information** and **current weather** — all displayed in a modern interface with a **Light/Dark theme toggle**.

- Fetch and display live data from public APIs  
- Manage component state with React hooks (`useState`, `useEffect`)  
- Pass data through props and keep components modular  
- Implement theme toggling with Light/Dark mode  
- Style and organize a layout using Tailwind CSS  
- Handle loading and error states gracefully  
- Deploy a modern React app using Vite  

 Key Features

GitHub Profile Card
Fetches data from the **GitHub REST API** and shows:
- Profile avatar  
- Public repositories count  
- Followers and following numbers  

 Weather Card
Uses the **OpenWeatherMap API** to display:
- Current temperature  
- Weather condition (e.g., sunny, cloudy, rainy)  
- Wind speed  
- Current time that updates automatically  

 Theme Switcher
Includes a toggle to switch between Light and Dark modes, instantly updating the look of the dashboard.
